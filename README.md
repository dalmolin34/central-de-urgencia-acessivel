# 🌱 EcoVida - Reciclagem e Meio Ambiente

## Sobre o projeto
O EcoVida é um site educativo que apresenta informações básicas sobre reciclagem e conscientização ambiental.

## Objetivo
Incentivar atitudes responsáveis e ensinar exemplos de separação de materiais recicláveis.

## Tecnologias utilizadas
- HTML5
- CSS3

## Páginas do site
- Início (`index.html`)
- Sobre (`sobre.html`)
- Reciclagem (`reciclagem.html`)
- Contato (`contato.html`)

## Paleta de cores
- Verde: `#2E7D32`
- Verde escuro: `#1B5E20`
- Verde claro: `#A5D6A7`
- Branco: `#FFFFFF`
- Cinza claro: `#F2F2F2`

## Como executar
Abra a pasta no Visual Studio Code e abra o arquivo `index.html` em um navegador.

## Observação
O formulário da página Contato é apenas demonstrativo. O projeto utiliza somente HTML e CSS, sem JavaScript ou servidor para envio de mensagens.
