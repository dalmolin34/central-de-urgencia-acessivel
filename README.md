# central-de-urgencia-acessivel
Projeto acadêmico de um site de urgência acessível para pessoas surdas. A proposta inclui atendimento por videochamada em Libras, comunicação por texto, localização automática por GPS e acesso rápido ao SAMU, Polícia e Bombeiros. O objetivo é promover inclusão, autonomia e segurança. Projeto em desenvolvimento.
